Sneaking and stealth mechanic:

This project is an Unreal Engine gameplay mechanic prototype which was developed via C++.
This allows the AI to move to where the player last currently was, changing animations depending on it.

How to Download and run the project:

Open the GitHub Repository link.
Download or clone the repository.
Open the .uproject file in Unreal engine
Let Unreal Engine rebuild any project files if asked.
Open the main level to test the mechanic.

Unreal Engine 5.6 Will be needed.

Visual Studio will be needed.

The controls are default Unreal settings, apart from:

SHIFT, that will be used to allow the player to sprint.
CTRL, that will be used to allow the player to crouch.

The mechanic uses C++ to handle:

SHIFT and CTRL:
AI Detection
Debug logs and blackboard changes
Animation changes
